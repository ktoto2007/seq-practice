## Таблица `cars` (автомобили)
 
Поля таблицы:
 
- `brand` — марка автомобиля (строка, обязательное)
- `model` — модель (строка, обязательное)
- `year` — год выпуска (целое число)
- `price` — цена в рублях (число с плавающей точкой)
- `isAvailable` — доступен ли для продажи (логическое значение)
## Запуск
 
```
npm install
node app.js
```
 
Программа подключается к базе, создаёт таблицу, добавляет три автомобиля,
выводит все записи в консоль и закрывает соединение.
